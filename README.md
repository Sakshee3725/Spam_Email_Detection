# Spam Email Detection Machine Learning Model

A ready-made spam email classifier in Python using **Multinomial Naive Bayes** and **Scikit-Learn**.

---

## 🚀 Commands to Run

### 1. Install dependencies
```bash
pip install -r requirements.txt
```

### 2. Run the Model (with sample email tests)
```bash
python simple_spam_detector.py
```

### 3. Test your own emails interactively
```bash
python test_interactive.py
```
Type any message in the terminal, press Enter, and get the instant verdict!
